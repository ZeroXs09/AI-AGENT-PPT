# Perbaikan FlyPtx: Keamanan, Progress Real, Tema Sinkron, Riwayat Disk, Model Switcher

## Context
Audit menemukan 15 kelemahan; kamu memilih 4 area untuk dikerjakan + 2 permintaan tambahan: hapus "Ruang pribadi" dari sidebar, dan tambahkan model switcher. (Pertanyaan model dijawab di implementasi: kode lama mencoba 5 ID model berantai, dan `gemini-3.8-flash` yang jadi andalan BUKAN ID model yang valid di API Google — jadi selama ini live call gagal di model pertama lalu jatuh ke fallback. Rantai diganti ID model asli + pilihan manual.)

## Perubahan

### 1. `server.js` — ditulis ulang penuh
- **Progress real**: `POST /api/generate-ppt` langsung balas `{jobId}`, pekerjaan berat jalan di background; endpoint baru `GET /api/generation-status/:jobId` melaporkan step 1–4 asli (via callback `onProgress` dari pipeline). Job dibersihkan setelah 30 menit.
- **Riwayat di disk**: folder `generated/` (auto-create) menyimpan `deck_*.pptx` + `deck_*.json` (metadata). Saat server start, registry di-hydrate dari disk → "Presentasi saya" awet restart. `/api/download/:fileId` dan `/api/recent-presentations` baca dari registry disk-backed; hapus cache memori + expiry 1 jam.
- **Rate limiting**: middleware per-IP sederhana (6 request/menit) pada `/api/generate-ppt`, tanpa dependency baru.
- **Validasi API key** di `/api/save-key`: panjang 20–120, charset `[A-Za-z0-9_-]`, tolak format jelas salah dengan 400.
- **Model param**: whitelist `['auto','gemini-flash-latest','gemini-2.5-flash','gemini-2.5-flash-lite','gemini-2.5-pro']`, diteruskan ke agent.

### 2. `services/geminiAgent.js` — edit terarah
- Ganti rantai model: hapus ID palsu (`gemini-3.8-flash` dll), ganti dengan `gemini-flash-latest` (alias resmi Google, selalu valid) → `gemini-2.5-flash` → `gemini-2.5-flash-lite`. Param `model`: jika user pilih model spesifik, model itu dicoba duluan lalu fallback.
- Tambah `onProgress(step, label)` → dipanggil di tahap analisis (1), narasi Gemini (2), visual (3); step 4 dari server.
- Validasi hasil Gemini: `deck.slides` harus array non-kosong, kalau tidak throw → lanjut model berikutnya (bukan crash).
- Timeout model pro lebih longgar (45 dtk) vs flash (25 dtk).

### 3. `services/pptGenerator.js` — edit terarah
- Ganti 8 palet acak (Ocean Blue/Purple/Orange/…) jadi **2 palet brand sinkron dengan web**: Forest Dark (`#101A14`/`#16211A`/aksen `#4F9A6D`/krem `#E9EFE4`) dan Forest Light (`#F2F6F2`/putih/aksen `#2F7C55`) — dipilih sesuai `theme` dari request, konsisten satu deck.
- Netralkan jitter: `getRandomOffset()` → 0 dan `getLayoutVariation()` → baseValue (fungsi tetap ada, semua pemanggil tetap jalan) — menghilangkan posisi acak yang bikin elemen tak sejajar antar slide.

### 4. `public/index.html` — edit terarah
- **Hapus "Ruang pribadi"**: blok tombol workspace-picker di sidebar + CSS `.workspace-*` + override light theme-nya; breadcrumb jadi cukup "Presentasi baru".
- **Model switcher** di composer toolbar (select bergaya `select-pill`, sebelum pilihan jumlah slide): Otomatis / Gemini Flash terbaru / 2.5 Flash / 2.5 Flash-Lite / 2.5 Pro. Pilihan disimpan di `localStorage('flyptx_model')`.
- **Polling progress**: handler "Buat presentasi" dirombak — POST dapat jobId → poll status tiap ~800ms → stepper 1–4 mengikuti step ASLI server (hapus animasi setTimeout palsu) → selesai = render kartu slide + tombol unduh; error = toast.
- **Anti-XSS**: helper `escapeHtml()` diterapkan ke semua interpolasi konten Gemini (title, subtitle, badge, layout, points, cards, keyMetric, speakerNotes, imageUrl) dan nama file user di recent cards, toast upload, aria-label. Logika lain tak disentuh.
- Copy label status: "Gemini 3.8 Flash aktif" → "Gemini Flash aktif"; plan user → "Gemini Flash".

### 5. Tidak berubah
`imageService.js`, `package.json` (nol dependency baru), struktur folder selain `generated/` baru, semua fitur upload/paste/template/navigasi lain.

## Verifikasi
1. Start ulang server background (yang lama sudah mati).
2. `curl /api/status` → modelsSupported baru.
3. `curl POST /api/generate-ppt` (prompt uji, 5 slide) → jobId; poll `generation-status` → step maju 1→4 nyata → done.
4. `GET /api/download/:fileId` → 200 file pptx; restart server → `GET /api/recent-presentations` masih menampilkan deck (bukti persist).
5. `POST /api/save-key` dengan key sampah → 400; burst 7x generate → 429.
6. Browser: sidebar tanpa "Ruang pribadi", model switcher tampil, generate via UI → stepper jujur, kartu slide muncul, unduh jalan; buka PPTX hasil → tema hijau forest (bukan ungu/biru acak).
7. Cek sintaks JS inline `index.html` dengan `new Function(...)`.
